# Synthèses PDF

Branche tenue à jour par l'action « Synthèse PDF »
(`.github/workflows/synthese.yml` sur `main`) à chaque fusion dans
`main`, pour la version 231bfb3. Elle n'a qu'un commit, remplacé
à chaque fois : ne pas y travailler.

* [`pdf/synthese.pdf`](pdf/synthese.pdf) : synthèse de tous les
  programmes (tableaux et courbes sur dix ans, propriétés, sensibilités).
* [`pdf/synthese-orientation-d.pdf`](pdf/synthese-orientation-d.pdf) :
  synthèse du Texte Orientation D seul, avec ses grands principes et le
  classement de ses mesures (rubicons, paramétrables, négociables).
* [`pdf/livret-orientation-d.pdf`](pdf/livret-orientation-d.pdf) :
  livret de campagne du Texte Orientation D (préambule, texte détaillé
  des mesures par thématique, séparées en rubicons, paramétrables et
  négociables, bilan chiffré).

Les autres PDF (une synthèse par moteur contribué, le programme complet
de chaque parti) sont dans l'artefact `synthese` de l'action (90 jours).
